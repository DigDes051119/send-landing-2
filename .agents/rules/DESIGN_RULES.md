# Правила дизайна Send Messenger

- Сверяйте цвета, шрифты, радиусы и анимации с `src/styles/index.css` и `DESIGN_SYSTEM.md`.
- Сохраняйте существующие состояния и motion-последовательности при рефакторинге.
- Используйте React и TypeScript; сохраняйте семантическую разметку, доступность с клавиатуры и `prefers-reduced-motion`.
- Не добавляйте продуктовые сведения, домены или возможности, которые не подтверждаются сайтом.
- Для растровых изображений используйте lossless WebP; SVG и ICO оставляйте в подходящем исходном формате.
