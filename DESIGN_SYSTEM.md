# Дизайн-система Send Messenger

Этот файл описывает фактические основы оформления сайта. `src/styles/index.css` остаётся источником истины для размеров, цветов и анимаций.

## Визуальные токены

- Основной акцент: `--brand: #2563c9`; тёмный и светлый варианты: `--brand-deep: #0f2f63`, `--brand-light: #5790e6`.
- Фон: `--background: #f2f2f7`; карточки: `--surface-card: #fff`.
- Основной текст: `--ink: #0a0a0a`; вторичный: `--ink-soft: #717784`.
- Разделители и декоративные поверхности: `--hairline: #e6e8ec`, `--ghost: #d7dae1`.
- Основной шрифт — Onest с системным sans-serif fallback.

## Компоновка

Страница построена из последовательно расположенных секций. Главный экран и демонстрация чатов используют общий телефонный макет; его положение связано с прокруткой. Заголовки и карточки раскрываются при появлении в области просмотра. Блок вопросов использует физическую анимацию, а экран установки — анимированный переход из меню.

## Правила изменений

- Сохраняйте существующие CSS-классы и состояния `is-ready`, `is-inview`, `is-active` и классы секционных анимаций.
- Не заменяйте таймлайны прокрутки и переходов стандартными переходами без проверки поведения страницы.
- Предпочитайте существующие CSS-переменные новым цветам и значениям.
- Поддерживайте клавиатурный доступ, семантические заголовки и `prefers-reduced-motion`.
- Растровые материалы сохраняются в lossless WebP. Логотипы и иконки в SVG остаются векторными.
